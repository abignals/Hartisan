# Version Documents avant l’essai classique

Copie des composants et styles avant l’ajout de la variante classique. Les fichiers JSX sont archivés avec l’extension `.txt` pour éviter de les inclure dans les outils frontend.

Comparaison visuelle immédiate :
- Ancien style : http://localhost:5173/documents?demo=1&style=original
- Essai classique : http://localhost:5173/documents?demo=1

Le paramètre `style=original` désactive la feuille de styles classique grâce à une classe de page. Les fichiers archivés conservent le code de référence si la page évolue ensuite. `etabli.css` est une copie de référence des styles partagés, pas un fichier à restaurer globalement : des collègues peuvent continuer à le modifier.
